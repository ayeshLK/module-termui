This tutorial builds a small agent-style harness: a prompt, streamed answers, tool calls with
approval, and a status line. Every step is a complete program that compiles and runs, and each one
extends the one before it.

Each step has a recording or a test you can run, and the programs are the files CI builds, in
[`examples/tutorial`](https://github.com/ayeshLK/module-termui/tree/main/examples/tutorial). The tutorial
uses a scripted model, so it needs no account, key or network, and says where a real model would plug in.
The finished harness, with more features, is
[`examples/agent-harness`](https://github.com/ayeshLK/module-termui/tree/main/examples/agent-harness).
