In this step the list grows: press `a`, type an item and press Enter. Typing needs a text input, and termui has
one, the `LineEditor`.

## What changes

- The program has two modes. In browsing mode keys move, check and delete. In adding mode every key goes to a
  `LineEditor`, until Enter adds the item or Escape gives up.
- `update` now only routes a key to the right mode, and each mode has its own function.
- `view` shows the editor under the list while you are adding.

## The program

Start from step 2's program. You make three changes, and `bal build` compiles after each.

### 1. The editor

Add this import, in alphabetical order with the others:

```ballerina
import ayesha/termui.input;
```

Add these two fields to `TodoList`, after `selected`. `adding` says which mode the program is in, and `editor`
is the line editor. `multiline = false` makes Enter submit instead of starting a new line.

```ballerina
    boolean adding = false;
    private input:LineEditor editor = new (multiline = false);
```

### 2. Update

Replace `update` with these three functions. `update` receives every message, then sends key and paste events
to `typing` while you are adding and to `browsing` otherwise. `browsing` is step 2's `update` plus `a`, which
starts an add. `typing` hands the event to the editor: `handleEvent` returns a `Submitted` result on Enter, which
appends the item unless it is blank, and a key that the editor ignores, like Escape, gives up.

```ballerina
    public function update(termui:Message message) returns termui:Command? {
        if message is termui:InputEnded {
            return termui:quit();
        }
        if message is term:KeyEvent|term:PasteEvent {
            return self.adding ? self.typing(message) : self.browsing(message);
        }
        return;
    }

    // Browsing: move, toggle, delete, start an add, or quit.
    function browsing(term:KeyEvent|term:PasteEvent message) returns termui:Command? {
        if message is term:PasteEvent {
            return;
        }
        string key = message.key;
        if key == "up" {
            self.selected = int:max(self.selected - 1, 0);
        } else if key == "down" {
            self.selected = int:min(self.selected + 1, self.items.length() - 1);
        } else if key == " " && self.items.length() > 0 {
            self.items[self.selected].done = !self.items[self.selected].done;
        } else if key == "d" && self.items.length() > 0 {
            _ = self.items.remove(self.selected);
            self.selected = int:max(int:min(self.selected, self.items.length() - 1), 0);
        } else if key == "a" {
            self.adding = true;
        } else if key == "q" {
            return termui:quit();
        }
        return;
    }

    // Adding: the line editor handles the keys; enter appends the item, escape gives up.
    function typing(term:KeyEvent|term:PasteEvent message) returns termui:Command? {
        input:EditResult result = self.editor.handleEvent(message);
        if result is input:Submitted {
            if result.text.trim() != "" {
                self.items.push({text: result.text.trim()});
                self.selected = self.items.length() - 1;
            }
            self.adding = false;
        } else if result == "ignored" && message is term:KeyEvent && message.key == "escape" {
            self.adding = false;
        }
        return;
    }
```

### 3. View

While you are adding, the editor draws itself under the list with the prompt `new: `, and the selection marker
is hidden so only one thing looks active. The empty-list line now says how to add an item. Replace `view` with
this one:

```ballerina
    public function view() returns text:Span[][] {
        text:Span[][] lines = [];
        foreach int i in 0 ..< self.items.length() {
            Item item = self.items[i];
            boolean current = i == self.selected && !self.adding;
            lines.push([
                {text: current ? "> " : "  "},
                {text: item.done ? "[x] " : "[ ] ", style: {dim: item.done}},
                {text: item.text, style: {dim: item.done, bold: current}}
            ]);
        }
        if self.items.length() == 0 {
            lines.push([{text: "Nothing to do. Press a to add an item.", style: {dim: true}}]);
        }
        if self.adding {
            lines.push(...self.editor.render(60, "new: "));
        } else {
            lines.push([{text: "up/down move   space done   a add   d delete   q quit", style: {dim: true}}]);
        }
        return lines;
    }
```

Run it and press `a`:

```sh
bal run
```
