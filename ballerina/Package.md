## Overview

`ayesha/termui` is a terminal UI toolkit for building polished, interactive, agent-style command-line
applications in Ballerina: an inline live region, committed scrollback, streaming output, and
non-blocking input.

> This package is under development. See the project's OpenSpec changes for the design.

## Modules

The package's modules are documented in their own `Module.md` files as they are added.
